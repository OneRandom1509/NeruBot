# NeruBot
Yet another general-purpose discord bot written in Rust using [poise](https://github.com/serenity-rs/poise) (built on top of [serenity](https://github.com/serenity-rs/serenity))

## Commands
- `!ping` / `/ping`
- `!http [status_code]` / `/http [status_code]`
- `!verify` / `/verify` (admin only)
